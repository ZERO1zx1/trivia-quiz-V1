## 👤 1. Хэрэглэгчийн Профайл ба Сошиал Боломжууд

Хэрэглэгчийн профайл нь тоглогчийн виртуал хувь хүн (Identity)-ийг харуулахаас гадна бусад тоглогчидтой харилцах гол төв юм.

* **Визуал тохируулга (Visuals & Customization):**
  * **Avatar & Dynamic Frames:** Аватар зураг болон дэлгүүрээс авсан хөдөлгөөнт хүрээ (*Neon, Golden Flame, 8-Bit Retro*).
  * **Profile Banner & Title:** Профайлын арын фон зураг болон нэрний доор харагдах цолууд ([⚡ Эйнштейн], [🧠 Бүгдийг Мэдэгч]).
  * **Badge Showcase:** Хамгийн ховор 3–5 тэмдэгтийг байршуулах хэсэг.
* **Статистик ба Амжилт (Stats & Metrics):**
  * **Level & XP Bar:** Одоогийн түвшин ба дараагийн түвшин хүрэх прогресс.
  * **Rank & Elo Rating:** Одоогийн эрэмбэ (*Gold II, Diamond I*) болон өрсөлдөөнт горимын Elo оноо.
  * **Win Rate & Accuracy:** Нийт тоглолтын тоо, хожлын хувь (%) болон асуултын нарийвчлал.
  * **Streaks:** Өдөр тутмын ба асуултын дараалсан зөв хариултын рекорд.
* **Сошиал ба Интерактив Боломжууд:**
  * **/rep (Respect):** Өдөрт 1 удаа өөр тоглогчид нэр хүндийн оноо өгөх.
  * **Challenge / Duel:** Профайл дээрээс нь шууд 1v1 бооцоот тоглоомд дуудах.
  * **Marriage System:** Бусад хэрэглэгчтэй виртуал байдлаар гэрлэх 💍.
  * **Gift System:** Бусад тоглогчид кофе, титэм эсвэл XP Boost бэлэглэх.

## 🔒 2. Нууцлал, Аюулгүй Байдал ба Модераци

* **Профайлын Харагдах Төлөв (Profile Visibility):**
  * **Public:** Бүх хэрэглэгчид профайлыг бүрэн харна.
  * **Friends Only:** Зөвхөн баталгаажсан найзууд нэвтэрч харна.
  * **Private:** Зөвхөн Нэр ба Аватар харагдана, бусад статистик, түүх нууцлагдана.
* **Нарийвчилсан Нууцлал (Custom Privacy):**
  * Тоглолтын түүх нуух, Онлайн төлөв нуух (*Invisible*), Дуудан тоглох (Duel) хүсэлтийг хаах, Инвентарь нуух.
* **Аюулгүй байдлын хэрэгслүүд:**
  * **Block User:** Тухайн хэрэглэгчийг блок хийж, харилцааг хаах.
  * **Report Profile:** Зохисгүй нэр, зурагтай профайлыг Админд мэдээлэх.
  * **Gmail Notifications:** Сэжигтэй нэвтрэлт, OTP баталгаажуулалт, болон нууц үг сэргээх линк илгээх.

## 🎮 3. Тоглоомын Модуль ба Механик (Game Engine)

* **Тоглоомын Горимууд (Game Modes):**
  * **1v1 Ranked Duel:** Elo чансааны дагуу таарч (Matchmaking) бодит цагт өрсөлдөх.
  * **Classic / Custom Room:** Найзуудтайгаа өрөө үүсгэн ангилал, цагаа тохируулан тоглох.
  * **Time Attack:** Богино хугацаанд хамгийн олон асуултад хурдан хариулах.
  * **Survival Mode:** Буруу хариулвал хасагдах (Elimination) горим.
  * **Solo Practice:** Өрөө үүсгэхгүйгээр дасгал хийх.
* **Спортын тооцоолол ба Anti-Cheat:**
  * **Elo Rating:** Сул тоглогчийг хожвол бага оноо, хүчтэй тоглогчийг хожвол өндөр оноо авна.
  * **Anti-Cheat:** 0.6 секундээс бага хугацаанд хариулсан тохиолдолд бот гэж үзэн блоклоно.
  * **Dynamic Timer & Combo:** Хариулах хугацаа багасах тусам авах оноо буурна. Дараалж зөв хариулбал Combo үржүүлэгч (1.25x, 1.5x, 2x) идэвхжнэ.
  * **Lifelines (Тусламж):** 50/50, Time Freeze, Skip, Double Score.

## 🐳 7. Сервер Инфраструктур ба Деплоймент

```
               +----------------------------------------+
               |              Nginx Proxy               |
               +-------------------+--------------------+
                                   |
         +-------------------------+-------------------------+
         |                                                   |
+--------v-------+                                   +-------v--------+
| Flask Web App  | <--- WebSockets (Socket.IO) --->  |  Discord Bot   |
+--------+-------+                                   +-------+--------+
         |                                                   |
         +-------------------------+-------------------------+
                                   |
                      +------------v------------+
                      | Redis Cache / Queue     |
                      +------------+------------+
                                   |
                      +------------v------------+
                      | PostgreSQL Database     |
                      +-------------------------+
```

* **Docker & Docker Compose:** Flask, PostgreSQL, Redis, Nginx болон Discord ботыг тусдаа контейнерт ажиллуулна.
* **WebSocket Real-Time:** Олон тоглогчийн тулааныг ямар ч хоцролтгүй шилжүүлнэ.
* **Redis & RQ:** Илгээх имэйл, Premium хугацаа шалгах зэрэг арын процессыг (Background Tasks) ачаалалгүйгээр гүйцэтгэнэ.

## 🌐 Олон хэлний дэмжлэг (Flask-Babel)

### Орчуулгын санг бэлтгэх
```bash
# 1. Орчуулгын түлхүүрүүдийг татах
pybabel extract -F babel.cfg -o messages.pot .

# 2. Монгол хэлний орчуулгын сан үүсгэх (анх удаа)
pybabel init -i messages.pot -d translations -l mn

# 3. Орчуулгын санг шинэчлэх (шинэ түлхүүр нэмэх)
pybabel update -i messages.pot -d translations -l mn

# 4. Орчуулгын файлыг засварлах
#    translations/mn/LC_MESSAGES/messages.po файлд msgstr хэсгийг бөглөх

# 5. Compile хийх
pybabel compile -d translations
```

### Хэрэглэгч хэл солих
- Navbar дээрх `🇬🇧 EN` / `🇲🇳 MN` товчлууруудаар шууд солино.
- Тохиргоо хуудаснаас мөн сонгож болно.
- Сонгосон хэл нь хэрэглэгчийн профайлд хадгалагдана.
