# 📂 TriviaVerse V1 Standardized Project Structure

Төслийн хавтас болон файлын бүтцийг Flask-ийн стандарт (Best Practice) хэлбэрт оруулж шинэчиллээ.

## 🏗️ Үндсэн бүтэц

```text
trivia-quiz-V1/
├── app/                    # 🌐 Flask Application (Үндсэн логик)
│   ├── models/             # 📊 Өгөгдлийн сангийн моделиуд
│   ├── routes/             # 🛣️ Вэб чиглүүлэлтүүд (Blueprints)
│   ├── sockets/            # 🔌 WebSocket үйл явдлууд
│   ├── static/             # 📁 Статик файлууд (CSS, JS, Images, Uploads)
│   ├── templates/          # 🎨 HTML темплэйтүүд (Jinja2)
│   ├── utils/              # 🛠️ Туслах функцууд
│   ├── extensions.py       # 🔌 Flask өргөтгөлүүдийн тохиргоо
│   └── __init__.py         # 🚀 Апп эхлүүлэх ба Blueprint бүртгэл
├── discord_bot/            # 🤖 Discord Bot-ын эх код
│   ├── cogs/               # ⚙️ Ботын модулиуд (Economy, Quiz, etc.)
│   └── bot.py              # 🔌 Ботын үндсэн файл
├── docs/                   # 📚 Баримт бичгүүд
│   ├── DOCUMENTATION.md    # Техникийн дэлгэрэнгүй
│   ├── project_structure.md # Энэхүү файл
│   └── audit_plan.md       # Шалгалтын төлөвлөгөө
├── tests/                  # 🧪 Тестүүд
│   └── test_routes.py      # Чиглүүлэлтийн тест
├── migrations/             # 📦 Өгөгдлийн сангийн шилжилтүүд
├── translations/           # 🌍 Олон хэлний орчуулгын файлууд
├── config.py               # ⚙️ Аппликейшны тохиргоо
├── run.py                  # 🚀 Вэб серверийг ажиллуулах файл
├── requirements.txt        # 📦 Шаардлагатай сангуудын жагсаалт
└── README.md               # 📖 Төслийн танилцуулга
```

## 🛠️ Хийгдсэн өөрчлөлтүүд:

1.  **Templates & Static нэгтгэл**: Үндсэн хавтсанд байсан `templates/` болон `static/` хавтаснуудыг `app/` хавтас руу шилжүүлж, дотор нь байсан давхардсан файлуудыг нэгтгэсэн.
2.  **Flask Тохиргоо**: `app/__init__.py` файл дахь Flask-ийн `template_folder` болон `static_folder` тохиргоог стандартын дагуу автоматаар (дотоод хавтаснаас) уншдаг болгож зассан.
3.  **Root Цэвэрлэгээ**: Үндсэн хавтсанд байсан техникийн баримт бичгүүдийг `docs/`, тестүүдийг `tests/` хавтас руу тус тус шилжүүлж, үндсэн хавтсыг цэгцэлсэн.
4.  **Discord Bot**: Өмнөх шатанд хийгдсэн Cogs бүтэц хэвээр хадгалагдсан.
